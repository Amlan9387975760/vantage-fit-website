# Vantage Fit Website

A corporate wellness platform landing page built with vanilla HTML, CSS, and JavaScript.

## Live URLs

| Resource | URL |
|---|---|
| GitHub Repository | https://github.com/Amlan9387975760/vantage-fit-website |
| Live Site (GitHub Pages) | https://amlan9387975760.github.io/vantage-fit-website/ |

## Project Structure

```
vantage-fit-website/
├── index.html      # Main page markup
├── style.css       # Styles and responsive layout
├── script.js       # Interactivity and animations
└── README.md       # This file
```

## Sections

| Section | Description |
|---|---|
| Navbar | Sticky nav with smooth scroll links and CTA button |
| Hero | Dark gradient banner with headline, sub-copy, and animated metric cards |
| Features | 6-card grid — Fitness Challenges, Mental Wellness, Goal Tracking, Rewards, HR Analytics, Mobile-First |
| How It Works | 3-step visual flow — Onboard, Launch, Track & Reward |
| Testimonials | 3 quote cards from fictional enterprise clients |
| Contact | Lead-capture form with submission feedback |
| Footer | Brand logo, copyright, and policy links |

## Tech Stack

- **HTML5** — semantic markup, single-page layout
- **CSS3** — CSS custom properties, Grid, Flexbox, backdrop-filter, clamp()
- **JavaScript (ES6)** — IntersectionObserver for nav highlight, form UX, entry animations
- **Hosting** — GitHub Pages (static, no build step)

## Deployment

The site is deployed via GitHub Pages from the `main` branch root (`/`).  
Any push to `main` automatically updates the live site within ~1 minute.

```bash
# To update the site
git add .
git commit -m "your message"
git push
```
